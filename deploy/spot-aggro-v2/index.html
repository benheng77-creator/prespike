            SPI Formula

            Squeeze Pressure Index — NEVER MODIFY
            SPI = 0.35 × max(0, -fz)/5
    + 0.25 × oi
    + 0.25 × div
    + 0.15 × liq
            fz = funding_z (30d z-score of funding rate)
            oi = open interest growth rate
            div = price-funding divergence
            liq = liquidation cluster proximity

            Entry Gates

            ALL must pass to enter
            ENTER iff:
  SPI ≥ 0.65 (relaxed to 0.30 after 5 dry cycles)
  AND funding_z ≤ -1.0 (shorts paying)
  AND depth ≥ 10× position size
  AND consensus ≥ 0.45 (5-LLM Bayesian)
  AND conflict ≤ 0.75
            Consensus: 5 LLMs — Haiku + GPT-4o-mini + Gemini Flash + DeepSeek + Mistral
            Confidence cap: 0.70 per member (prevents domination)
            KL early stop: after 3 members if posterior stable
            Opus veto: fires on conflict > 0.70

            TP / SL / Trailing

            Dynamic from SPI
            TP = 0.008 + 0.037 × SPI
SL = -(0.005 + 0.010 × SPI)

Trailing stop:
  Activates at 60% of TP
  Trails at 60% of peak gain

            Sizing

            1/3rd Kelly
            base = capital × 0.95 / 3

size = base × sigmoid(consensus)
     × spi_scale(spi)
     × risk(drawdown, conflict)
            Max positions: 3
            Deploy ceiling: 95% of capital
            Min trade: $5

            BLITZ MODE

            Cascade-fade concentration
            BLITZ iff:
  SPI ≥ 0.85
  AND blitz_readiness > 0.60 (from MIO)
  AND dd_level < 1
