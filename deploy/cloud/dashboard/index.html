SPI Formula

Squeeze Pressure Index — NEVER MODIFY
SPI = 0.35 × max(0, -fz)/5
    + 0.25 × oi
    + 0.25 × div
    + 0.15 × liq
fz = funding_z (30d z-score of funding rate)
oi = open interest growth rate
div = price-funding divergence
liq = liquidation cluster proximity
